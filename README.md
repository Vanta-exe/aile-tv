# Aile TV

Anne ve baba için Android TV'de uydu alıcısı gibi çalışan, sade ve bozulmaz canlı TV uygulaması.

- Açılınca son izlenen kanal tam ekran başlar; menü yok.
- Kumanda: Yukarı/Aşağı kanal değiştirir, OK büyük yazılı kanal listesini açar, rakamlarla kanal numarası tuşlanır.
- Geri tuşu uygulamadan çıkarmaz.
- Kanal listesi ve yayın linkleri bu repodaki imzalı `channels.json` üzerinden uzaktan güncellenir.

**Durum:** Planlama aşaması (henüz kod yok).
